# User Stories - StackOverflow Clone

---

## Authentication

1. As a new user, I want to sign up so that I can ask questions and help others.

2. As a registered user, I want to log in so that I can access my account.

3. As a registered user, I want to log out so that my account stays safe.

4. As a logged-in user, I want to edit my profile so that others know about my skills.

5. As a logged-in user, I want to view my profile page so that I can see my questions and answers.

---

## Questions

6. As any visitor, I want to see all questions so that I can browse what people are asking.

7. As any visitor, I want to click a question and see full details with answers so that I can solve my problem.

8. As a logged-in user, I want to ask a question with title, body, and tags so that others understand my problem.

9. As the question owner, I want to edit my question so that I can fix mistakes.

10. As the question owner, I want to delete my question so that I can remove it if no longer needed.

---

## Answers

11. As a logged-in user, I want to post an answer so that I can help others.

12. As the answer owner, I want to edit my answer so that I can fix errors.

13. As the answer owner, I want to delete my answer so that I can remove wrong answers.

14. As the question owner, I want to accept one answer as correct so that others know what worked.

---

## Voting (Likes)

15. As a logged-in user, I want to upvote good questions and answers so that the best content rises to the top.

16. As a logged-in user, I want to downvote bad questions and answers so that poor content goes down.

17. As any user, I want to see total votes on any question or answer so that I know which content is trusted.

---

## Following

18. As a logged-in user, I want to follow other users so that I can see their activity.

19. As a logged-in user, I want to unfollow users so that I can stop seeing their activity.

20. As a logged-in user, I want to see my followers and who I follow so that I know my connections.

---

## Threaded Comments

21. As a logged-in user, I want to comment on a question so that I can ask for clarification.

22. As a logged-in user, I want to comment on an answer so that I can discuss the solution.

23. As a logged-in user, I want to reply to someone's comment so that I can have a conversation.

24. As the comment owner, I want to edit my comment so that I can fix mistakes.

25. As the comment owner, I want to delete my comment so that I can remove it if needed.

26. As any user, I want to see all comments in thread format so that I can follow the conversation.

---

## Error Handling

27. As any user, I want to see a 404 page when I visit a wrong link so that I know the page does not exist.

28. As any user, I want to see a 403 page when I try to edit someone else's content so that I know I am not allowed.
